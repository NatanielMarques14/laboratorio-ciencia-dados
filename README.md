# Laboratório de Ciência de Dados

Repositório da disciplina **Laboratório de Ciência de Dados** contendo materiais de estudo, explicações comentadas em Python, exercícios desenvolvidos em aula e práticas extras voltadas para programação e análise de dados.

## Conteúdo

- Explicações comentadas em Python
- Exercícios realizados em aula
- Exercícios extras para treinamento
- Manipulação e análise de dados
- Visualização de dados
- Práticas com bibliotecas do ecossistema de Ciência de Dados

## Tecnologias Utilizadas

- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook
